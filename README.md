# Состав на игру — генератор постера (HC Dinamo Minsk)

Веб-приложение: редактор состава + векторный постер (SVG) с экспортом в PNG.
Без зависимостей и сборки. Опубликовано на GitHub Pages с входом по паролю.

## Как устроена защита паролем

Сайт статический, поэтому приложение не просто «спрятано за формой», а
зашифровано целиком: `app.html` шифруется паролем (PBKDF2-SHA256, 310 000
итераций + AES-256-GCM) и встраивается в `index.html`. Без пароля содержимое
приложения из исходников страницы не извлечь. Расшифровка происходит локально
в браузере (WebCrypto), пароль никуда не отправляется. После входа пароль
хранится в `sessionStorage` вкладки, чтобы перезагрузка не просила его снова.

## Пересборка после правок приложения

1. Отредактируйте `app.html` (это и есть приложение; оно в `.gitignore` и
   никогда не публикуется в открытом виде).
2. Соберите публичный `index.html`:

```
PASSWORD='пароль' node build_gate.mjs
```

3. Закоммитьте и запушьте — GitHub Pages обновится сам.

## Локальный запуск без пароля

Откройте `app.html` в браузере (Safari или Chrome).

## Использование

- Сверху слева — три вкладки постера, у каждой свои номера, дата и имя файла:
  - «Игра» — состав на игру: 4 звена, 13-й нападающий, 3 пары, 7-й защитник, вратари.
  - «Тренировка» — тренировочная группа (неиграющий состав): по 3 ряда нападающих
    и защитников плюс вратари, без 13-го и 7-го.
  - «PK» — сочетания в меньшинстве: 4 двойки нападающих, 3 двойки
    защитников и один вратарь.
- Слева — редактор: дата матча, формат, разрешение и номера всех звеньев, пар и вратарей.
- «Формат постера» — 3:4, 2:3, 9:16, 1:1, 4:3, 16:9.
- «Разрешение» — длинная сторона PNG: 1600, 2400 (по умолчанию), 3200 или 4000 px;
  вторая сторона считается из выбранного формата.
- Номера вводятся без фамилий. Пустое поле убирает свитер из состава — так можно
  оставить 12 нападающих без 13-го или 6 защитников без 7-го.
- «Скачать PNG» — файл `dinamo-lineup-…`, `dinamo-practice-…` или
  `dinamo-pk-ДД-ММ-ГГГГ-формат.png` сохраняется в Загрузки.
- «Сбросить к дефолту» — возврат дефолта активной вкладки: игра (9-17-23 / 11-14-77 /
  19-22-88 / 21-63-94, 13-й — 71, пары 4-55 / 6-44 / 27-91, 7-й — 2, вратари 30 и 1),
  тренировка (10-16-29 / 58-81, защитники 3-5 / 8, вратарь 35),
  меньшинство (нападающие 19-22 / 21-63 / 11-14 / 9-17, защитники 27-91 / 4-2 / 6-44, вратарь 30).

## Как устроен рендер

Постер рисуется как inline SVG в клубных цветах (голубой #45B7E8, чёрный, белый):
тёмный фон, логотип «Динамо» по центру с лёгким размытием, белые свитеры выездной
формы — голубой воротник, голубые полосы на рукавах, тёмный номер с голубым контуром,
раглан-швы и сетчатая текстура. Все свитеры одного размера в пределах постера.
Заголовок зависит от вкладки: СОСТАВ НА ИГРУ / GAME LINEUP,
ТРЕНИРОВОЧНАЯ ГРУППА / PRACTICE GROUP либо МЕНЬШИНСТВО / PENALTY KILL
(длинный заголовок автоматически сжимается по ширине постера). Названия блоков
выводятся на двух языках: НАПАДАЮЩИЕ / FORWARDS, ЗАЩИТНИКИ / DEFENSEMEN,
ВРАТАРИ / GOALTENDERS (на вкладке PK — ВРАТАРЬ / GOALTENDER).

Раскладка подстраивается под формат: приложение считает вариант в одну колонку
(нападающие → защитники → вратари) и в две (нападающие | защитники и вратари),
затем выбирает тот, где свитеры крупнее и постер заполнен по высоте. 13-й нападающий
и 7-й защитник выводятся по центру под своими звеньями и парами.

Готовый SVG растрируется через canvas в PNG выбранного разрешения — все цифры и
тексты остаются точными (вектор). PNG предрендерится в фоне при каждом изменении,
кнопка скачивает готовый файл синхронно.
